1. Khung Có Sẵn (Bấm là cài)

Lưu ý bắt buộc khi đổi khung ảnh:

1. Trong Shadowrocket, hãy TẮT các Module Locket cũ đi để tránh bị đè khung Shin-chan mặc định.

2. Tạm tắt DNS Chống thu hồi trong Cài đặt máy trước khi bấm đổi khung.

3. Bấm chọn khung trên web -> Bật kết nối Shadowrocket -> Xóa app Locket tải lại (hoặc Đăng xuất rồi Đăng nhập lại) là lên khung mới 100%!

2. Cài Config, Module & DNS

Cài Module Gốc (.sgmodule) Cài Config Gốc (.conf) Cài DNS Trần Hải (Bật sau khi đã nhận khung)
